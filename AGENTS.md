# CHIMERA

A physical-modeling voice synthesizer: a Rust engine (wasm in an AudioWorklet, native for tests
and the CLI) under a React UI. See the README.

## Working here

- Do what was asked, the simplest way. Side work nobody asked for (experiments, tooling, paid
  runs) is a proposal with its cost. If the work grows well past the estimate, stop and say so.
- Before repeating or reversing earlier work, read its history (`git log -- <path>`, `git log -S`).
- Commit small. The subject names what changed and the trap, in searchable words; the body gives
  the why, what you ruled out, what you ran (with numbers) and what you didn't test.
- Keep each fixed bug's reproduction as a test.
- Code outranks this file: fix the file when they disagree. When something breaks unnoticed, add
  a rule here, with a check.

## Map

- `crates/chimera/`: the engine (no I/O). `crates/chimera-wasm/`: the browser's C ABI.
  `crates/chimera-cli/`: `chimera render | compare csd | diagnose | calibrate`.
- `src/wasm/`: the UI's facade over the engine. `src/worklet/`: the AudioWorklet. `src/ui/`: React
  and the canvas renderers.
- `native/`: macOS SwiftUI apps, Metal renderers and loopback-only MCP services
  (`native/ChimeraMac/MCP/`). `native/project.yml` generates the combined `ChimeraMac` debug
  shell (8642, local audio) plus independent Play (8643), Speak (8644), Sing (8645), Beatbox
  (8646), Head (8647), Gender Age (8648) and Viewer (8649) targets. Head exclusively owns
  `AudioController` / `AVAudioEngine` for the independent apps; controllers never create audio
  outputs or render a duplicate head. Shared engine types, `RemoteHeadClient`, continuous
  `VowelSpace` and `HeadTelemetryFrame` live in `Engine/`. Head's `/head/stream` is NDJSON at
  about 30 Hz with 10 Hz geometry. Control commands are ordered, Stop precedes a replacement
  utterance, and pending source/articulation/Body updates coalesce; do not replace the stream
  with MCP polling. `MIDIInputController` and `MIDIInputView` are shared by Play and Sing. Play auto-enables MIDI and maps PolyBrute Ribbon CC9 to ±5 semitones, Morphée X/Y CC114/115 surjectively onto the continuous vowel map (measured ranges X 0...127, Y 0...104) and Z CC89 to inverted breathiness (0→1, 127→0), pitch bend to ±12 semitones, note velocity to pressure, aftertouch/channel pressure to vibrato depth, CC74 to brightness and CC1 also to vibrato depth. With no MIDI, Play explicitly initializes pressure 8, breathiness 1 (matching inverted Z=0), vibrato 0, brightness 0.25, centered vowels and zero pitch offset. This is global expression, not per-note MPE voices.
  Every app target explicitly includes `cmudict.txt.gz` and the shared Rust-build/dictionary-copy
  script aliases in `project.yml`; dictionary load failure is visible, not a silent G2P fallback.
  App icons use the apps' IPA phonemes and are generated by `native/Tools/GenerateIcons.swift`;
  Gender Age puts `eɪdʒ` above blue/pink gender symbols. Edit the generator and regenerate all
  sizes instead of editing individual PNGs. The `NativeApp` template explicitly sets `ASSETCATALOG_COMPILER_APPICON_NAME=AppIcon` for every target. Each independent app has a README in its own Apps
  subdirectory with its icon, identity, workflow and build instructions; keep these pages aligned
  with the target. Gender Age owns the shared triangular Body palette, with continuous BodyMix
  weights, matching outline colors and exact pointer-release application. Its Whisper switch is a
  persistent Head state applied to every controller's events, not a local voiced toggle; Play has
  no duplicate Hold Breath button. Head coalesces audio
  model and geometry rebuilds separately from UI updates. Camera-only updates must reuse Head's
  cached scene rather than rebuilding anatomy during a drag. LKG camera-array matrices are cached
  by camera/Body values and GPU frame counts are throttled before they reach SwiftUI. Speak's chat box accepts only Ollama
  user prompts: prompts are never spoken; validated generated English replies are spoken
  immediately. Assistant rows have a Play button that replays only that generated reply through
  Head and supersedes earlier generation/speech. Direct text/IPA remains available through the
  non-chat `chimera_speak` MCP call.
  The visualizations sit above Conversation and use shared components. Viewer owns
  the full consonant chart and shared acoustic views. Beatbox has editable beat notation,
  a synchronized 16-step matrix and real transport/stop commands. Pads trigger on mouse/key down,
  with 1–9 following pad order and 0 fixed to `m`; ignore editing fields and key repeat. Sing has an
  editable piano roll, one validated engine `Syllable` per note, presets, tempo/vibrato, CoreMIDI
  and on-screen note input, Ollama lyric generation and Head-clock playhead telemetry. Remote song
  commands are ordered, Stop precedes replacement playback, pending play requests coalesce, and
  Head alone calls the existing song/note planners. Sing reuses the shared score, spectrogram,
  tube and vocal-fold views and never includes HeadCanvas.
  Shared Canvas tube/vocal-fold views live in `Views/AcousticViews.swift`. Head's optional LKG
  window uses StreamQuilt with live Bridge calibration/default quilt data, mirrored local camera
  orientation, independent FOV/Focus/Parallax and the same visual snapshot; LKG lifecycle must
  never affect audio, MCP or NDJSON.
- `tests/`: bun tests on the wasm build. `tools/`: e2e, layout lint, spectrogram, speech judge.
- `docs/`: architecture, the engine contract (`rust-engine.md`), the UI look, the singer judge,
  and the hill-climb rules.

## Rules

- **The engine's contract** (`docs/rust-engine.md`): transcendental math only through
  `chimera::math`, no allocation while rendering, output independent of block size. `cargo test`
  enforces each.
- **Any change to the sound or the plans fails the golden tests, by design.** Re-bless with
  `CHIMERA_BLESS=1 cargo test --workspace --no-fail-fast`, run twice. Human-voice audio, plans
  (including the beat sounds' gestures and the beat player), the tract geometry and the human
  airway's transfer functions re-bless; see `crates/chimera/tests/golden/README.md` for the rest.
- **`*.generated.json` tables are regenerated (`chimera calibrate`, `tools/gen-*`), never edited.**
  Vowel calibration isn't bit-reproducible, so rerun it only when the formants should move.
- **`src/wasm/chimera.wasm` is a gitignored build product.** After a Rust change, `bun test tests`
  alone tests the old engine: use `bun run test`. Don't share a cargo `target/` between checkouts.
- **Gesture records are defined in `crates/chimera-wasm/src/lib.rs`** and mirrored by
  `src/wasm/wire.ts` and `native/ChimeraMac/Engine/AudioController.swift`. Change all three and
  bump `LAYOUT_VERSION`.
- **The wasm loads before the UI.** A module that calls the engine at import must not be reachable
  from `src/main.tsx`'s static imports. Check: `bun tools/e2e.ts` against `bun run preview`.
- **DOM content flows in `.screen-body`, never absolutely positioned.** Check: `bun run lint:layout`.
- **Nothing copyrighted goes in git.** `public/shows/` is gitignored; never ship CSD audio or
  anything derived from it.
- **Voice tuning follows `docs/hill-climb/README.md`** and never edits its judges.
